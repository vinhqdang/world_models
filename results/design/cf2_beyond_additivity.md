## Candidate 1 (recommended): Polarized Cross-World Kriging (PCK)
Idea: the gauge theorem leaves free the cross-action covariance kernel K_z(a, a') = Cov(Y(a), Y(a') | z); only its diagonal is factual. If the disturbance enters through channels affine in known action features (additive offset plus command-proportional gain, as control-affine physics gives at first order), K is bi-affine in (a, a') and its diagonal, a quadratic in a, determines the off-diagonal by polarization. Counterfactual = best linear cross-world predictor: y_hat(a') = mu(z, a') + K(a', a) [K(a, a) + N]^(-1) (y - mu(z, a)). Residual reuse is K(a', a) = K(a, a) (gain I); the outcome-blind predictor is gain 0; the sd-ratio / location-scale rule is the unsigned, correlation-one special case.
Assumptions: channel-affine class F(z, a, eps) = m(z, a) + sum_j psi_j(a) B_j(z, eps), psi(a) = (1, a / a_lim), E B_j = 0; whitened factor form Y(a) - mu(a) = G(z, a) xi with G(z, a) = sum_j psi_j(a) G_j(z), Cov(xi) = I_r; K(a, a') = G(a) G(a')^T. Assumption V: products {psi_j psi_k} linearly independent on the action support (true for (1, a) with interior). Physical version: control-affine with uncertain drift and uncertain input gain (the union of the paper's separate-channel class and gain faults). No extra information beyond the paper's; nugget N fixed from factual readout error.
Pseudocode: Stage 0 the paper's encoder, predictor and readout. Stage 1 two-fold cross-fitted residuals. Stage 2 gain-channel head G_theta(H) with q x d x R outputs (R = 4), MLP 2 x 256 on pooled context; loss = Gaussian quasi-likelihood of r under N(0, G G^T + diag(n)) via Woodbury; Adam 1e-3 cosine, batch 1024, 20k steps, weight decay 1e-4, early stopping on held-out factual quasi-NLL; context-free closed form: regress r r^T on {psi_j psi_k} (Hildreth-Houck style), symmetrize, Burer-Monteiro lift to G (LBFGS, 8 restarts). Stage 3 factual certificates: V-condition singular value; lack of fit against an unrestricted heteroscedastic head (flag above 0.02 nats per coordinate; third cumulants must be cubic in psi); factual interaction ratio rho_hat(a, a') = tr[(G(a') - G(a))(G(a') - G(a))^T] / tr[G(a') G(a')^T]; gauge width check. Stage 4 query: u = G(H, a)^T [G G^T + diag(n) + tau I]^(-1) r (tau = 1e-3 x mean trace / d), y_hat(a') = mu(H, a') + G(H, a') u; hindsight planning computes u once; persistent faults treat u as a recursive least-squares state.
Candid novelty: known ingredients: covariance regression (Hoff-Niu 1102.5721), random-coefficient regression and identification (Hildreth-Houck 1968; Beran-Hall 1992; Hoderlein-Klemela-Mammen 2010), BLUP/kriging, cross-world correlation as an unidentified sensitivity parameter for binary treatments (Bodik 2603.27320, 2507.12581). Claimed new: polarization identification of the cross-action kernel in action-conditioned dynamics with an exact characterization of the residual gauge; a maximality dichotomy (degree 2 brings the gauge back); physical derivation with rate/minimax separation from residual reuse on control-affine systems with uncertain gain; a factual interaction-ratio estimate inside the class; an amortized head and abduced coordinate u for planning. Hostile referee: "random-coefficient BLUP applied to world models".

Theorems.
- Thm 1 (polarization and exact gauge; proved, elementary): under V the variance function determines S_jk = (M_jk + M_jk^T)/2 and nothing else at second order; compatible set S + antisymmetric blocks. For d = 1 K is fully identified; fully identified if dim(col G_j cap col G_k) <= 1 (scalar disturbance; generically 2r <= d + 1); counterexample Y = (I +- a J) xi with J the rotation generator. Generic identifiability for r <= d conjectured (numerically R^2 0.976-0.997).
- Thm 2 (maximality; proved by example): with psi = (1, a, a^2) two Gaussian worlds share factual laws but differ in K by (a - a')^2. Corollary: the paper's Y(a) = U vs Y(a') = 1 - U example is resolved within the affine class by intermediate actions.
- Thm 3 (dominance and exact excess risk; proved): for any linear rule T_L, R(L) = R(L*) + ||(L - L*) K(a, a)^(1/2)||_F^2 with L* = K(a', a) K(a, a)^+; R(L*) <= min{tr Var Y(a'), tr Var Delta}, strict against residual reuse iff Cov(Delta, Y(a)) != 0, equal in every additive world; zero iff the disturbance is observable through a; minimax over worlds sharing K. Fitted version adds ||e(a') - L e(a)||^2 (common-mode error cancels fully only at L = I).
- Thm 4 (short-time rate separation; proof sketch): residual reuse risk h^2 tr Var(sum_j w_j (psi_j(a') - psi_j(a))) + O(h^3), so rho_RR does not vanish with h; PCK error <= h beta + (1 + ||L||) C h^2 with beta = 0 under observability, rho_P = O(h^2).
- Thm 5 (minimax on the enlarged class; proof sketch): 4C^2h^4/(1 + C^2h^2) <= minimax <= sup risk(PCK) <= (1 + l)^2 C^2 h^4 while sup risk(RR) >= c h^2.
- Not proved: finite-sample rates for the neural head; the generic-identifiability conjecture; optimality for folds; any guarantee outside the class.

## Candidate 2: Echo kernel (novelty 0.20-0.25)
Lagged residual products under partial persistence are attenuated paired trials: E[r_t r_{t+1}^T | z, a_t, a_{t+1}] = kappa K(a_t, a_{t+1}), kappa identified on the diagonal; K obtained nonparametrically and used in the same kriging rule. Needs action-independent attenuation and new configs combining actuator_affine with iid_fraction < 1. Best use: factual falsification test for PCK.

## Candidate 3: additive transport coordinates (novelty 0.10-0.15; not recommended)
Monotone warps making the residual law action-independent; a direct post-nonlinear model application; fails the paper's lambda = 1 benchmark (multiplier changes sign) and folds.

## Recommendation of the designer
PCK, with the Echo kernel as its factual falsification test and the unsigned sd-ratio, rank-transport and input-disturbance rules as mandatory baselines. It does not address contacts; there it only flags lack of fit.
