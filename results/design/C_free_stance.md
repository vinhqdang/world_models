# Design C (free stance)

Bottom line of the designer: no design reaches novelty probability 0.3; the best (KR-WM) is about 0.20. About 77 arXiv-API queries and 19 web searches; every arXiv id fetched by id_list; classical references marked [mem] are from memory.

Findings that shaped the design
- Stochastic StochNav has no headroom for a world-model algorithm (learned-model planners 0.925 match the true-model planner 0.889). Only the discontinuity setting (0.10-0.24 against 0.74) has a large gap.
- That neighbourhood is more crowded than recorded earlier: ACID 2607.02403, WAV 2604.01985, PRISM-WM 2512.08411, RC-aux 2605.07278, 2410.07096, 2607.23602 (proposal overgeneration on OGBench-Cube), 2611.11780 (planners exploit persistent deterministic error).
- Reusing fixed random-number sets across receding-horizon replans has a 2018 precedent (1804.08766, per search summary), which weakens the noise-chaining claim.
- TwoRoom is saturated (2609.03565, 2605.22164); the usable benchmark hook is OGBench-Cube, where selection feasibility falls from 0.375 to 0.062 as the proposal pool grows from 72 to 288 (2607.23602).

## Candidate A (recommended): KR-WM, regularised-inclusion world model with Set-CEM

Idea. Learn the set-valued rho-regularisation of the dynamics (closed convex hull of the outputs over a rho-ball of inputs, a finite-resolution Krasovskii regularisation) as a signed residual hull around a smooth predictor, uniformly sound rather than marginally calibrated, and plan by min-max over that inclusion.

Problem. Deterministic f: Z = S x A -> S, S in R^d compact; logged D = {(s_i, a_i, y_i)}; no environment access in training; sampling MPC over N candidates of horizon H with cost c(s, g).
A1: f is L_f-Lipschitz on each connected component of Z minus a closed null switching set Sigma; jumps bounded by J. A2: a base predictor g whose error e = f - g is L_e-Lipschitz on each piece. A3: every z has a sample in its own piece within distance delta <= rho. A4: c is L_c-Lipschitz in s. F_rho(z) = cl conv f(B(z, rho)); Kf(z) = intersection over rho > 0 of F_rho(z).

Algorithm.
Training: (a) fit g by MSE (or take a frozen predictor); residuals r_i = y_i - g(s_i, a_i). (b) Neighbourhood of a box X = [c - w, c + w] and action a: Nb(X, a) = {i : dist_2(s_i, X) <= rho_s and ||a_i - a||_2 <= rho_a}; defaults rho_a = 0.15 x action-range diameter; rho_s = 0.95-quantile over data points of the distance to the 4th nearest neighbour among points with ||a_j - a_i|| <= rho_a. (c) One-step set map: lo = min over Nb of r_i - iota, hi = max over Nb of r_i + iota (coordinatewise); if Nb is empty, lo = -r_max, hi = +r_max. Output box c' = g(c, a) + (lo + hi)/2, w' = Lambda w + (hi - lo)/2, Lambda = 1 for residual-form predictors. (d) Calibrate iota on a 10% held-out split as the 0.995-quantile of the coordinatewise distance of held-out residuals to their neighbour hull; require held-out containment >= 0.995.
Planner (Set-CEM): X_0 = {s_0}; X_{k+1} from (c). J_pess(a) = sum_k 0.1 max_{X_k} c + max_{X_H} c; for c = ||x - g||^2 the max over a box is sum_j (|c_j - g_j| + w_j)^2. Standard CEM on J_pess (N = 100, 3 iterations, 10 elites, H = 14, replan every step, as in results/p4/pilot_b.py).
Ablations only after the kill test: width loss (fine-tune g to minimise the mean local residual range); branch splitting (up to 4 boxes when a hull is wide).

Claimed new step (narrow): the learned object is the regularised inclusion, a signed hull that contains the other branch of a discontinuity, not an error magnitude around a smoothed prediction; soundness is uniform over inputs, so it survives argmin selection; the planner-exploitable set is identified with the solution set of this inclusion. Signed hull against scalar ball is the ablation that must show a difference.

Theorems. A1 lower bound for any L-Lipschitz single-valued model: error at least (J - 2Lr)/2 at one of two points at distance r either side of a jump (proved). A2 uniform soundness and tightness: under A1-A3 with iota >= L_e rho, f(z) in F_hat(z) for all z simultaneously; away from Sigma by more than rho the width is at most 4 L_e rho + 2 iota (sketch). A3 exploit-set characterisation: if dist(g(z), F_rho(z)) <= eps for all z, every g-rollout solves x_{k+1} in F_rho(x_k, a_k) + B(eps); conversely any finite solution of the inclusion is reproduced by a continuous model with values in F_{rho+eta} (sketch; needs a careful write-up). A4 no optimism and pool monotonicity: J_true(a) <= J_pess(a) for every a, so the executed plan's true cost is at most the pool minimum of J_pess, non-increasing for nested pools (elementary). A5 price of pessimism: for plans staying away from Sigma, J_pess - J_true <= L_c H^2 (2 L_e rho + iota) with Lambda = 1 (sketch). A6 minimality: any sound set model with closed graph and convex values contains Kf [mem: Goebel, Sanfelice, Teel 2012; Hajek 1979]; convergence of F_hat to Kf conjectured.

If (iii) fails, stop. Compute under 2 CPU-hours with one torch thread.

## Candidate B: Reach-Hull projection
Learn by extremal (pinball, tau 0.99) regression from action-free transitions the support function h(s, w) of the one-step reachable set, and project each predicted step of the action-conditioned model onto the estimated hull (cyclic sweeps over 16-32 directions). Theorems: conv R(s) is Hausdorff-Lipschitz so h is learnable in sup-norm although f is discontinuous (sketch); projection onto an outer estimate never increases one-step error (proved); with an inner margin projected rollouts never cross a supporting hyperplane (sketch). Prior art: 2604.01985, 2210.01919, 2610.42146, 2607.02403, 2606.09311, 2312.10812, 2402.15391, 2110.06169, 1909.05477, 2011.09999, 2006.15085, 2008.10180, 2112.05745, 2303.17674, 2410.07096, 2605.07278, 2512.08991. Novelty 0.15; not piloted. Kill test: E1, E3, E4 with 1,300 labelled and 24,000 action-free transitions; pass at >= 0.70 x ceiling and >= best baseline + 0.10.

## Candidate C: persistent imagined worlds
The existing noise-chaining trick with theory: at an indifference point the per-replan flip probability is arccos(rho_c)/pi (0.5 for fresh draws, about 0.17 at r = 0.3, H = 10); an interior optimal refresh rate is conjectured. Novelty 0.08 (1804.08766, 1301.3878, 2611.11780, 2104.02213, 2008.06389). A section of an analysis paper, not a standalone algorithm.
