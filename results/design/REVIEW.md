# Adversarial review of the three designs

Scope: the three design files, results/p4/REPORT.md, paper/prior_art_feedback.md, the outline of paper/theory.tex; 23 arXiv abstract fetches and about 10 web searches. Statements about papers are from abstracts.

Confirmed: 2608.17956 (planner pinned at a mode boundary by a mode-blind model, localization budget kappa((eta-eps)/L)^(d+m); analysis paper on code world models, no algorithmic fix), 2409.08249, 2602.09368, 2609.03129, 2606.03521, 2010.08993, 2312.11329, 2610.06002, 2611.11780, 2607.23602 (also proposes a fix, ASAR, which must be a baseline), 2607.02403; consistent: 2512.08411, 2009.11193, 2604.01985, 2605.07278, 2410.07096, 2602.12047, 2606.15594, 1701.00178. ## Novelty
KR-WM: reviewer's novelty probability 0.12 (designer 0.20). Data-driven set-valued over-approximation propagated with interval methods and used for control exists (DaTaReach/DaTaControl 2009.12733, 2011.05524, 2106.10533); data-driven PAC symbolic abstractions (2104.13901) learn a set-valued successor relation per cell without a Lipschitz assumption, so a cell straddling a wall already contains both branches; robust control over abstractions is standard (SCOTS style; IMDP abstractions 2104.02172); data-driven reachability for PWA systems targets region boundaries (2504.04362); bounded-error PWA identification (Bemporad, Garulli, Paoletti, Vicino, IEEE TAC 2005); nonlinear set membership and kinky inference (Milanese and Novara, Automatica 2004; Manzano, Limon et al., Automatica 2020; 1701.00178; 2312.11329); min-max CEM over learned uncertainty (2010.07968, 2309.05582, 2606.03521); Krasovskii regularisation is textbook (Goebel, Sanfelice, Teel 2012). Strongest objection: a data-driven abstraction or set-membership enclosure is already sound across discontinuities, combined with robust CEM.
KR-WM plus graph-error merge: 0.15. The input-slack (Hausdorff) graph error is classical (Sendov; errors-in-variables; Bertsimas, Nohadani, Teo 2010); 2608.17956 owns the exploitation finding and localization bound.
Doob-ledger planning: 0.08 (P3 2610.06002, multi-stage scenario-tree MPC, MCTS subtree reuse, 1511.04992), and the designer's oracle pilot leaves about 2 points of headroom.

## Soundness
- A1 correct and trivial (overlaps 2608.17956).
- A2 holds only pointwise and under strong assumptions: the same-piece-sample assumption fails at corners and thin modes; iota calibrated as a held-out 0.995 quantile is a marginal guarantee that the argmin planner will find violations of (contradicting the project's own selection theory) unless iota comes from a uniform covering bound, which is cursed in dimension.
- Box propagation is wrong as written: for g(s, a) = s + h(s, a) the infinity-norm Lipschitz factor is 1 + ||Dh||, not 1, so Lambda = 1 breaks soundness after one step.
- Wrapping and width avalanche at Sigma are unaddressed; A5 grows as H^2 and excludes plans passing near Sigma.
- A3 converse is false as stated (a pseudo-orbit revisiting a state with different successors cannot be reproduced by a single-valued model).
- A4 elementary; A6 known; convergence to the Krasovskii regularisation only conjectured.
- Design A: T1, T3 elementary; T2 standard covering; T4 overstated (holds only for constant-radius tubes); T5 1-D sketch; T6 conjecture. Doob ledger: accounting identity plus standard results; nothing about the true environment.
- Theory would read to a referee as light theory decorating a heuristic.
- Latent spaces (32-192 dimensions; DINO-WM latents are patch grids): coverage needs about rho^-d samples, coordinatewise hulls widen every coordinate, the box cost becomes a data-density penalty, latent discontinuities are not axis-aligned, and a frozen encoder may smooth the jump away.

## Experiments
The pilot is not evidence (0.07 gap, SE about 0.055, one seed, post-hoc radius, non-monotone gate curve). The kill test leaks tuning from E1, uses only axis-aligned walls, and lacks baselines a referee will demand: grid or kNN successor-set abstraction with the same Set-CEM (the killer baseline), set-membership or kinky-inference envelope, GP or local conformal tube with Set-CEM, label-free hybrid identification and mixtures, ensemble worst-member CEM, output-ball PGD robust MPC, kNN density penalty, ACID, ASAR in latent experiments, kNN point model, supervised oracle gate as a separate ceiling.

## Decision: NO-GO for a new-algorithm paper
Novelty 0.12-0.15; closest prior art already contains the "both branches in the set" property; elementary theory with a soundness error and an internal contradiction; non-significant post-hoc pilot; the latent path likely degenerates into a density penalty. An analysis paper is also weak now (2608.17956, 2611.11780, 2607.23602 own the main findings).

## Optional reversal test (4-6 CPU-hours; pre-registered, no changes afterwards)
Environments: E1 wall-stay (development only, not counted); E2 rotated walls at 30 and 60 degrees; E3 door 0.2 wide; E4 planar pusher with a disc; E5 a 6-10-dimensional contact task. Data: 24,000 uniform transitions (also 6,000 for E3). Seeds: 5 data seeds x 200 tasks = 1,000 paired tasks per arm per environment; hyperparameters tuned on dev seeds 900-902 and frozen.
Arms: true model; MLP (300 epochs, and 16x data); ensemble worst-member CEM; label-free hard-gated mixture; supervised oracle gate (reference ceiling); kNN point model; kNN density penalty; ACID; grid/kNN successor-set abstraction with Set-CEM; LACKI envelope with Set-CEM; local conformal ball with Set-CEM; PGD output-ball robust MPC; KR-WM with Jacobian-bounded Lambda and covering-bound iota; KR-WM with a scalar ball.
Metrics: success; success against N in {64, 256, 1024}; fraction of executed plans with J_pess >= J_true; containment of the worst selected plan; box width against horizon; wall-clock time.
Pass (all required): (1) pooled over E2-E5, KR-WM minus the best non-oracle baseline >= 0.08 with paired-bootstrap 95% CI excluding 0 and positive in at least 3 of 4 environments (Holm-corrected); (2) KR-WM beats the successor-set abstraction by >= 0.05 pooled; (3) success at N = 1024 >= success at N = 64 + 0.05; (4) J_pess >= J_true on >= 99% of executed plans including E5; (5) E5 success >= 0.70 x true model. Stop permanently if (1) or (2) fails. Reviewer's expectation: (2) fails because the successor-set abstraction matches KR-WM in 2-4 dimensions.
If it passes: title "Learning Finite-Resolution Krasovskii Inclusions for Sampling-Based Planning through Discontinuous Dynamics"; claims limited to the estimator with a sound box rollout, min-max Set-CEM with no-optimism and pool monotonicity under uniform soundness, and evidence against abstractions, set membership, ensembles and gates on low-to-moderate-dimensional contact tasks; non-claims: not the first exploitation finding, not the first data-driven set-valued model or robust planner, no latent results, no convergence to the Krasovskii regularisation.
