## Deviations, interpretations and caveats (all documented, none changed after seeing results)
- idt specification: `syn2.py` as written is a K=3 zero-mean scale-mixture with scalar noise (it gives 80.13 on tanh in `syn_a.log`). The protocol specifies the design-document model, so `k0_run.py` implements K=4 location-mixture sources (means initialised on linspace(-1.2, 1.2) plus 0.1 jitter per restart), per-step re-standardisation, diagonal noise with floor 1e-3, Adam 1e-3 cosine, 3000 steps, batch 512, clip 5, checkpoint every 500 steps. HH initialisation of G_q for all restarts; restarts differ in source initialisation and minibatch order only.
- All fits (HH lift, idt, rc_eb_gmm) use the 90% training split; the 10% split is used only for checkpoint and restart selection. 2x2 Cholesky replaced by closed-form inverse and determinant (identical math). hh_blup uses nugget max(sigma^2, 1e-3) as in syn2.
- Reference arms: the 4000-particle reference is not used. Gated exact Bayes: quadrature as above (converged: h=0.06 vs 0.03 differ by at most 0.004 R^2). Tanh exact Bayes: 3-D midpoint grid of 64 points per dimension in driver space; the resolution check (first 1000 test points) shows 64 points under-reads the 96-point value by 0.003 to 0.07 R^2, so the tanh reference is a slight lower bound; this does not affect any decision.
- glr_iso: the protocol asked for lambda by held-out factual NLL but gave no likelihood for a hard-decision rule. The NLL used is that of the subset mixture implied by the penalty (prior weight proportional to exp(-lambda|S|/2), plug-in least-squares amplitudes clipped to the learned 0.1%-99.9% source quantiles, learned noise). This criterion selected lambda = 2 in every run, although test R^2 is higher at lambda 6-8 for the gated settings (see per-setting lambda lines), so glr_iso as specified understates a tuned GLR by 1.5 to 2.5 points on gated data.
- idt seed 2, gated pi=0.15: the selected idt fit converged to a poor optimum (71.8 R^2; all four restarts had held-out NLL worse than rc_eb_gmm, see raw JSON), so the t-interval for that setting is wide. Without that seed the mean difference is +0.49 (seeds 0,1,3,4: +0.57, +0.70, +0.79, -0.08), still below +1.5; the pre-registered rule is applied to all five seeds. This is reported, not altered.
- idt has worse held-out factual NLL than rc_eb_gmm on both gated settings (K=4 location mixtures represent spike-and-slab less tightly than a 32-component full-covariance GMM) and equals it on tanh, yet idt is up to 0.2 points better on counterfactual R^2 in the settings where it converges; neither arm exceeds exact Bayes* (no sanity flag).
